# Holy Prop – Standalone-Paket

## Start

- Lokal im Browser: **`index.html`** oder **`holyprop.html`** öffnen.
- Warenkorb: **`holyprop-warenkorb.html`**

## Inhalt

| Datei / Ordner | Zweck |
|----------------|--------|
| `holyprop.html` | Landingpage |
| `holyprop-warenkorb.html` | Warenkorb |
| `holyprop.css` | Holy-Prop-Styles |
| `balko.css` | Gemeinsame Layout-/Komponenten-Basis |
| `styles.css` | Globale Styles (Friday-Circle-Basis) |
| `balko-cart.js` | Warenkorb (sessionStorage) |
| `balko-nutzungsbedingungen.html` | Link aus dem Warenkorb (Inhalt noch BALKO – bei Bedarf anpassen) |
| `assets/` | Logo, Hero-Bilder, Shop-Mockups, Projektbilder |

## Hinweise für den Upload / Host

- **Footer**: Links zu `impressum/`, `datenschutz/`, `kontakt/` – im Paket nicht enthalten. Entweder eigene Seiten ergänzen oder in `holyprop.html` auf die Ziel-URLs des Hosts ändern.
- **Formulare** (`holyprop-einrichtung` etc.) sind für **Netlify** angelegt (`data-netlify`). Auf anderem Hosting Anpassung nötig.
- Schrift **Inter** wird von Google Fonts geladen (Internetverbindung).

## Abgrenzung

Dieses Verzeichnis ist absichtlich **ohne** den Rest der Friday-Circle/BALKO-Site kopierbar versandbar.
